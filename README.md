# Samzytechh-website
The Samzy Techh University website is a modern, user-friendly platform showcasing the university’s programs, campus life, achievements, and student experiences. It provides clear information on academics, faculties, events, and admissions while highlighting innovation, leadership, and global impact.

Samzy Techh University Website

A responsive and visually engaging university website for Samzy Techh University, designed to showcase academic programs, campus life, events, and student testimonials. The website features modern UI components, interactive elements, and clear navigation to enhance user experience.

Features
Responsive Navbar: Includes a logo, navigation links, and a mobile-friendly hamburger menu.
Hero Section: Dynamic typing animation to welcome visitors, with call-to-action buttons for admissions and program exploration.
About Section: Highlights the university’s mission, values, and legacy.
Faculties & Programs: Showcases multiple faculties with images and descriptions.
Student Life & Events: Features campus activities, convocation, research conferences, and innovation challenges.
Testimonials & Impact: Displays alumni and student success stories.
Call-to-Action: Encourages prospective students to apply for admission.
Footer: Provides contact details, quick links, and university information.

Technologies Used
HTML5
CSS3 (linked via index.css)
JavaScript (for typing effect and mobile menu toggle)
